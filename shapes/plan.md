# Plan — template

A plan in force is a numbered list of jobs in the order they will be done, with what each gives the user and how it is judged. One plan at a time. Earlier plans move to `docs/history/` as record.

The coordinator derives each standard from the design; the plan carries them. See [roles/coordinator.md](../roles/coordinator.md) "What it decides, and how".
