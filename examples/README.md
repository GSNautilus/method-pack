# Examples

The files in this folder show what each kind of document looks like when filled in. They are small, synthetic examples for an imagined project — a command-line reading list called "Shelf". The project is a placeholder; the specific content does not matter. Read for the shape and replace the content in your head with whatever you are working on.

- [state.md](state.md) — the coordinator's current state.
- [handoff.md](handoff.md) — a handoff from a coordinator to a builder.
- [record.md](record.md) — a dated record of what a builder did on one job.
- [where-are-we.md](where-are-we.md) — a four-section review of a project.

These are examples, not templates. For templates with the fields called out, see [shapes/](../shapes/).
